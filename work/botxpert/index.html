BOTXPERT

No-Code AI Chatbot Builder

A web platform that lets anyone create a working AI chatbot from a single prompt, test it through an embeddable widget, choose between multiple AI agents, and connect it to tools like databases and calendars, without relying on heavy tech.

01 · OVERVIEW

The Problem

Building an AI chatbot typically means wiring together a language model, an agent framework, and a handful of integrations before anything actually works. BotXpert set out to remove that barrier entirely — letting someone with no technical background create a working AI assistant from a single prompt.

The challenge was designing a product that stays genuinely simple on the surface, one prompt, one chatbot, while still supporting real complexity underneath: multiple AI agents to choose from, and integrations ranging from databases to calendar tools.

02 · APPROACH

How We Solved It

Before designing anything, I studied a range of existing chatbot-builder tools already in the market to understand where their flows broke down for non-technical users, then designed BotXpert to improve on that baseline rather than simply matching it.

Every module — chatbot creation, agent selection, widget testing, integrations — was designed as its own considered flow rather than a generic settings panel, so a user never has to hold the whole system in their head to get one part working.

Key Research Findings
01

Built for Technical Users

Most existing chatbot-builder tools still expect users to configure prompts, models, and integrations manually before a chatbot does anything useful.

02

Testing Was an Afterthought

Competing tools often buried the "does this actually work" step behind extra setup, instead of making preview and testing immediate.

03

Integrations Meant Reading Documentation

Connecting a chatbot to a database or calendar tool typically required technical setup rather than a guided, in-product flow.

KEY DESIGN DECISIONS
Creation

One Prompt, One Chatbot

A user describes what they want in a single prompt and gets a working chatbot back, with no separate model, prompt-engineering, or setup steps required upfront.

Testing

Plug-and-Play Widget

Every chatbot can be tested immediately by grabbing its widget code and dropping it onto a website, so "does this work" gets answered in minutes, not after a deployment process.

Flexibility

Multiple Agents to Choose From

Users aren't locked into one AI agent — they can choose between multiple agents suited to different use cases, without needing to understand the underlying model differences.

Integrations

Connect to Any Tool

A guided integrations panel connects the chatbot to databases, calendar tools, and other systems, replacing manual API setup with an in-product flow.

03 · RESULTS

Outcome

Since launch, BotXpert has seen strong adoption from exactly the non-technical users it was designed for, with positive feedback centred on how quickly a working chatbot comes together, and steadily growing use of its tool integrations.

Strong Adoption among non-technical users
Positive Feedback on the single-prompt creation flow
Growing Usage of third-party integrations
04 · REFLECTION

What I Learned

Designing BotXpert reinforced that the hardest part of "AI for everyone" products isn't the AI, it's making genuine complexity disappear behind a single, confident action. Every extra decision surfaced to the user is a decision they didn't want to make.

Studying competitors before designing anything shaped the whole product for the better — I could see exactly where existing tools asked users to think like engineers, and designed around each of those moments deliberately.
