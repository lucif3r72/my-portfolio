WECARE

Seafarer Wellness App — Redesign

Redesigned Anglo-Eastern's WeCare app, used by seafarers and onshore staff for wellness tools, training schedules, forums, and peer appreciation, turning a cluttered, hard-to-navigate interface into a clean, accessible design system.

UI/UX Design Design System Accessibility Mobile Design
CLIENT Anglo-Eastern
ROLE UI/UX Designer
PLATFORM Mobile (Android & iOS)
STATUS Live on Play Store
YEAR 2025
Overview Research Process Design Results Reflection
01 · OVERVIEW

The Problem

The old WeCare app had a dark, crowded layout. Important features were hard to find, tap areas were small, and the navigation felt confusing, especially in the low-connectivity environments seafarers actually work in.

There was no consistent design system behind it, which made every update slower and riskier. The goal was to simplify the experience end to end without losing any of the app's wellness, training, and community features.

My Contribution
UI/UX Design Design System Component Library Accessibility (WCAG) Mobile Optimization
02 · APPROACH

How We Solved It

I introduced a white background for clarity, grouped features into logical sections, and built a modular design system so the app could scale without losing consistency. Accessibility and mobile responsiveness were treated as requirements, not afterthoughts.

Reusable components — cards, buttons, and navigation patterns — replaced one-off screens throughout the app, and features like AE Live, Medical Contact, and Appreciation were pulled forward so they're easy to find instead of buried.

Key Research Findings
01

Buried Features

A dark, crowded layout made important tools hard to find. Users had to hunt through confusing navigation to reach features they used regularly.

02

Failing at Sea

Small tap targets and a layout not built for mobile meant the app struggled specifically in the low-connectivity conditions seafarers actually work in.

03

No System Behind It

Without a consistent design system, every update meant rebuilding patterns from scratch, slowing the team down and creating visual drift over time.

KEY DESIGN DECISIONS
Visual System

Light, Breathable Layout

Replaced the dark, cluttered background with a white, semantic-colour layout that reduces visual noise and makes content easier to scan on deck or in transit.

Navigation

Clustered Bottom Nav

Swapped scroll-heavy navigation for a clustered bottom nav, cutting the steps between opening the app and reaching a core feature.

Component Library

Reusable Cards & Buttons

Built a set of reusable components optimized for mobile use, so new features and future apps can be assembled from the same system instead of one-off screens.

Accessibility

WCAG-Compliant Contrast

Raised colour contrast and tap-target sizing to WCAG-compliant levels, up from the low-contrast legacy UI, so the app is usable in bright, outdoor, on-deck conditions.

03 · RESULTS

Outcome

User feedback improved significantly and Appreciation usage climbed after launch. Navigation became faster and more intuitive, and the modular design system built for WeCare is now being reused across other Anglo-Eastern mobile apps.

42% Improvement in user feedback
3.5× Increase in Appreciation usage
Reused Design system now used across AE's app portfolio
04 · REFLECTION

What I Learned

This redesign was about making life easier for maritime professionals. By focusing on clarity and usability, WeCare became a tool that truly supports its users, whether they're onboard or onshore.

Building the design system as a first-class deliverable, not a byproduct, is what let it outlive this one app. That decision is now paying off across Anglo-Eastern's wider mobile portfolio.
